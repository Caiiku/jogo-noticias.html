# jogo-noticias.html
script para um jogo onde vamos fazer a diferença de notícias verdadeiras de notícias falsas. O jogo terá 3 fases  Fácil: 10 perguntas  Médio: 10 perguntas  Difícil: 10 perguntas  O jogo deve conter dados nas notícias (sejam elas reais ou fakes), imagens que estejam ligadas às notícias (sejam as verdades ou fakes)
